# Selected Rhythm v21 policy

[`memory.txt`](memory.txt) is the frozen prompt used for the selected 17-second,
25-note API episode: 24 Perfect / 1 Great / 0 Miss and two empty presses.
The retained opening word “Unsolved” is historical prompt text, not a live
status field. It is preserved so the selected prompt hash and evidence remain
verifiable; the run does not meet strict full-combo acceptance.

GPT receives full-board screenshots, public clocks, pending commands, receipts,
recent RTTs and this memory. Public calibration includes receptor y=717,
provisional speed 0.2404px/ms and approximate 50ms screenshot-time bias.
The formula in the memory is guidance for GPT to calculate its own absolute
click timestamps; the executor never evaluates that formula or repairs times.

The default recipe uses 2.5s visual approach with 1× music. It reuses the retained
chart; its historical filename/title does not make subsequent runs held out.
