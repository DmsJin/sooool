# Place the falling piece

You know Tetris. Each request shows the game screen (board, HOLD, one NEXT piece, score/lines/level; nothing is
annotated). The piece in play is the falling one, not yet part of the stack; it may already have fallen some rows.
Hollow outlines show where it would land if dropped where it is. Columns are numbered 0-9 from the left.

- `rot`: 0-3, orientation from the shape table below (rot0 is how the piece spawns; each +1 is a 90 degree clockwise turn).
- `col`: the column number of the LEFTMOST column the piece occupies after rotating. It is dropped straight down there.
- Holes are the main thing to avoid: an empty cell under a filled one stays unusable until every row above it is cleared.
  Before answering, compare several columns and rotations. If ANY spot lets every column under the piece rest
  directly on the stack (no empty cell left underneath), choose such a spot, even if it is one or two rows higher.
  Accept a gap only when no gap-free spot exists anywhere.
