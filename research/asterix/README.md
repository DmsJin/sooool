# Asterix research record

The selected policy is [V28, direct actions, one request, public English summaries](../../policies/asterix/v28/). Read [the autoresearch walkthrough](../../docs/asterix-autoresearch.md) and [evaluation recording protocol](../../docs/evaluation-records.md).

`evaluation-history.jsonl` records the milestones leading to the release. The selected raw campaign is in `artifacts/asterix/serial-selected/`. Candidate scoring is development evidence; game results remain separate from screenshot preferences.

Inactive candidate code, old executors and duplicate machine snapshots were removed from the active tree. Their exact earlier state remains at [source commit 053545c](https://github.com/sooool-project/sooool/tree/053545c1c27e6beccb80598e7a4d57f80865afc1/research/asterix) and the existing optional evidence archive. This keeps one runnable implementation without rewriting historical evidence. Other games retain their own research sources and recipes.
